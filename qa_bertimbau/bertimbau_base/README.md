# bertimbau_base

Esta pasta contém arquivos e scripts relacionados ao modelo Bertimbau Base.


## Estrutura e significado dos arquivos

- **main.py**: Script principal para execução do modelo Bertimbau Base.
- **main_dora.py**: Treinamento ou inferência usando abordagem DoRA.
- **main_lora.py**: Treinamento ou inferência usando LoRA.
- **main_predict.py**: Script para realizar predições com o modelo.
- **main_qdora.py**: Variante de DoRA para experimentos específicos.
- **main_qlora.py**: Variante de LoRA para experimentos específicos.
- **preprocessing.py**: Processa os dados antes do treinamento ou inferência.
- **postprocessing.py**: Processa os resultados após a inferência.
- **analysis_bertimbau_base.ipynb**: Notebook para análise dos resultados e métricas.

### Pastas
- **figures/**: Gráficos e visualizações geradas.
- **results/**: Resultados das avaliações e predições.
