# Efficient-FineTunning-QA-PEFT
This repo evaluates PEFT and quantization on BERTimbau for PT-BR QA (SQuAD-BR), following Green AI principles. Analysis of 40 setups shows LoRA on BERTimbau-Large reaches 95.8% performance with 73.5% less training time, proving encoder-based models are more memory and time-efficient than generative ones for this task.
